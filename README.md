# lab6-oop-numerical-integration-variant11

Структура проекту: Створено базовий клас інтегратор і від нього створені підкласи конкретних інтеграторів. Потім в мейн викликані поліморфізмом всі 3 інегратори через один цикл.

Інструкції запуску: у target_function реалізувати бажану функцію, оптім в main() заповнити params: {"a":нижня межа,"b":верхня межа} i в eps бажану точність

Моє завдання: функція: f(x) = ln(x)/(x+1) межі інтегрування a = 1 b = 2 точність eps = 0.00002

Таблиця результатів (eps = 0.00002)

|--------------------|-------------------|----------------------|
|rectangular|32|0.147220687|
|trapezoid|64|0.147220676|
|simpson|8|0.147220676|
